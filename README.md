基于51单片机的智能电风扇与灯光控制系统
一个融合 语音识别、按键交互、PWM调速、超声波避障、LCD显示、数码管显示和LED跑马灯 的综合实训项目。
适用于单片机课程设计、物联网入门实验或DIY智能家居原型。

📖 项目简介
本项目基于 STC89C52RC（或兼容的51系列单片机），实现了一台智能电风扇的完整控制逻辑。通过 天问语音识别模块（或任意串口通信模块）发送指令，配合 独立按键 作为本地输入，采用 PWM（脉宽调制） 技术对直流电机进行无级调速（三挡位 + 停止）。同时，系统包含 超声波测距 模块实现自动避障（距离过近时强制停机），8位LED跑马灯 作为氛围灯效，LCD1602 和 数码管 双重显示当前挡位状态。所有功能模块协同工作，展示了51单片机外设驱动的典型应用。

⚙️ 核心代码逻辑
1. PWM调速（定时器0）
定时器0配置为 16位模式，中断周期 100µs（10kHz）。

全局变量 duty_cycle 决定占空比（0~100），定时器中断中根据计数值控制 P1^0 高低电平。

三个挡位占空比：GEAR1_DUTY=50，GEAR2_DUTY=75，GEAR3_DUTY=100。

2. 串口指令解析（中断方式）
串口中断接收字节，存入全局变量 uart_cmd，并置标志 uart_cmd_flag。

主循环轮询标志，执行对应命令：

0x34 → 3挡（正转）

0x35 → 停止

0x33 → 开启跑马灯

0x32 → 关闭跑马灯

0x36 → 1挡

0x37 → 2挡

0x38 → 3挡

3. 按键扫描（消抖 + 等待释放）
三个按键各自对应挡位1、2、3，按下后更新 duty_cycle 和 current_gear，并更新LCD显示。

采用10ms软件消抖，并等待按键释放，避免重复触发。

4. LCD1602显示
初始化函数 lcd_init() 设置5×8点阵、开显示、清屏、输入模式。

lcd_show_char(ch) 在 第一行第4列 显示单个字符（当前挡位数字）。

5. 超声波避障
每20次主循环执行一次测距（节流控制），避免频繁测距占用过多CPU。

测量距离 < 2cm 时，立即将电机停止（duty_cycle=0），并点亮LED（P2^0=0）。

6. LED跑马灯（非阻塞）
使用 led_flow_flag 控制启停，led_flow_cnt 计数，每300ms更新一次流水效果。

通过移位操作实现8个LED依次点亮，循环往复。

7. 数码管显示
每次主循环刷新一次数码管，输出 current_gear 对应的段码（0~3），位选为低电平有效。

🚀 快速开始
硬件搭建
按照引脚连接表接好所有外设。

确保电机驱动电源独立（避免干扰单片机）。

将天问语音模块的串口与单片机串口交叉连接（TX→RX，RX→TX），共地。

软件准备
使用 Keil C51 打开项目，编译生成 HEX 文件。

使用 STC-ISP 或其他烧录工具下载到单片机。

上电测试
数码管和LCD初始显示“0”，电机停止。

按下 KEY1→电机启动1挡，LCD显示“1”；按KEY2→2挡；按KEY3→3挡。

发送串口指令（例如通过串口助手发送十六进制 36）可切换到1挡。

发送 33 开启跑马灯，32 关闭。

将手靠近超声波模块（<2cm），电机立即停止，LED点亮，移开后恢复。

⚠️ 注意事项与已知问题
引脚冲突：
代码中 跑马灯（P2.0~P2.7） 与 LCD控制引脚（P2.5~P2.7） 共用P2端口，会导致LCD显示异常。
✅ 解决方案：将跑马灯移至其他端口（如P1剩余引脚或P3），并修改 LED_Flow_Process 中的 P2 为新的端口。

LCD显示简单：当前仅显示单个字符，可扩展显示更多信息（如“Fan: 1”）。

超声波超时保护：代码中使用 Delay10us 累计计数，可能存在精度误差，建议改用定时器计时。

串口指令无校验：未对数据帧头、校验和进行判断，存在误触发风险，可增加简单协议。

电机驱动：若使用L298N，需注意逻辑电平匹配，建议使用光耦隔离。
